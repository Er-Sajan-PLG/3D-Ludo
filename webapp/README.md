# 3D Ludo Next.js Webapp

This `webapp` folder now contains a Next.js scaffold for the 3D Ludo frontend.

Getting started:

```bash
cd webapp
npm install
npm run dev
```

Then open `http://localhost:3000`.

Routes:
- `/` - home
- `/game` - play game
- `/ui`
- `/auth`
- `/store`
- `/lobby`
- `/friends`
- `/inventory`
- `/settings`
- `/engine`

API routes:
- `/api/game` - game state and actions

Notes:
- This is a frontend scaffold only.
- Use `next build` and `next start` for production preview.
