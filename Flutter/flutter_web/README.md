# Flutter Web Scaffold

This folder contains a minimal scaffold for a Flutter Web application.

To run locally you need the Flutter SDK installed. Example commands:

```bash
cd Flutter/flutter_web
flutter pub get
flutter run -d chrome
```

Modules:
- UI
- Authentication
- Store
- Lobby
- Friends
- Inventory
- Settings
- 3D Game Engine (Unity integration to be handled via exported builds)
